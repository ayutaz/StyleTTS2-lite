# TUSIDE 起業加速プログラム 募集要項サマリ

作成日: 2026-01-14
対象資料: TUSIDE EAP 2026_募集要項.pdf

## 1. 募集要項（PDFより）

### 目的
- TOKYO SUTEAM事業に基づき、先端科学分野に特化した支援体制を構築
- 東京都における起業数の増加、ユニコーン創出を目的とする

### 支援対象者
- 一般社会人、教職員、学生
- 原則として法人登記前の個人
- 例外: 既存法人を有する者が新たに別法人を設立する場合は、既存法人と異なるアイデア・事業内容で、東京都に本店登記する場合に限り支援対象

### プログラムの概要
- 事前課題e-learning、事業計画策定
- インプット講義
- メンタリング
- GPUクラウドサーバー無償利用
- 技術・専門領域に関する個別相談
- ピッチイベント
- 協業先紹介、実証実験費用の一部支援
- 先輩起業家による講演

### 支援期間
- 2027年2月末まで

### 応募方法・必要書類
- 応募フォームより申込
- 身分証明書（免許証、学生証、住民票 等）
- 未成年または学生（学部生）の場合、保護者による同意書

### 応募期限
- 2026年1月25日（日）23:59

### 連絡先
- 東京理科大学インベストメント・マネジメント株式会社
- SUTEAM事業担当
- Tel: 03-5225-2080
- E-mail: incubation@tusim.co.jp

以下は運営から提供された情報で、PDF本文には明記がありません。

- 専門家メンタリング・PoC支援・ピッチ登壇機会あり
